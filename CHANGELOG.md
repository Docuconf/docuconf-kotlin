## 0.1.0

First version: typed configuration contracts for Kotlin services on [Hoplite](https://github.com/sksamuel/hoplite),
implementing spec `v1alpha1`. Artifacts: `dev.docuconf:docuconf-kotlin-core` and `dev.docuconf:docuconf-hoplite`.

### Features

* `docuconf-kotlin-core` (Kotlin Multiplatform): the contract model, CUE and Markdown writers, value checks, Go
  durations and RE2 patterns.
* `docuconf-hoplite`: annotations on Hoplite data classes for descriptions, secrets, constraints, URL schemes, list
  bounds (`itemMin`/`itemMax`) and file inputs; contract export (API and CLI); boot validation that reports every
  violation at once with stable error codes.
* Config-file overlays between base files and the environment, injector reference checks, contract-first mode and
  the shared conformance runner.
* The `orders` example service.
